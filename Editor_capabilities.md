## Modes
Although inspired from Nano, the Femto editor borrows the VI editor's modes, though with some differences.

### Normal mode (editing)
In Femto, the normal mode is the editing mode (like in Nano).

### Command mode
When the `command` key is pressed, the editor enters the Command mode.

### Fast editing mode
This mode is similar to VI's normal mode
